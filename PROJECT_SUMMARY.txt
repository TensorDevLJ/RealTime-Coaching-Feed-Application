⚡ QUICK START (2 MINUTES)
───────────────────────────────────────────────────────────────────────────

Using Docker (Recommended):
  1. Extract feed-app.zip
  2. cd feed-app
  3. docker-compose up
  4. Wait for: "Server running on http://localhost:5000"
  5. Open: http://localhost:3000

Services:
  • Frontend: http://localhost:3000
  • Admin: http://localhost:3000/admin
  • API: http://localhost:5000/api/feed
  • Health: http://localhost:5000/api/health

Manual Setup:
  • Backend: npm install && npm run dev (port 5000)
  • Frontend: npm install && npm run dev (port 3000)
  • Requires PostgreSQL + Redis running locally
